# Gradio — превратить бота в настоящий чат в браузере

До этого ты запускал ботов в терминале с заранее вписанным вопросом. **Gradio**
позволяет за ~10 строк превратить функцию в **настоящее окно чата в браузере** —
печатаешь вживую, как в ChatGPT.

## Что такое Gradio

Это библиотека Python, которая делает из твоей функции **веб-интерфейс**: чат,
форму, кнопки. Никакого знания HTML/CSS — Gradio рисует интерфейс сам.

```
терминал со скриптом   →   Gradio   →   живой чат в браузере
(вписанный текст)                        (печатаешь сам, в реальном времени)
```

## Минимальный код (вся суть Gradio)

```python
import gradio as gr

# Функция чата: получает сообщение пользователя и историю, возвращает ответ.
def chat(message, history):
    return "Ты написал: " + message      # сюда подставляется вызов ИИ

# ChatInterface превращает функцию в окно чата. launch() — открывает его.
gr.ChatInterface(chat).launch()
```

> ⚠️ Если у тебя старая версия Gradio (до 6.0), может понадобиться
> `gr.ChatInterface(chat, type="messages")` — в старых версиях был ещё формат
> `type="tuples"`, и его требовалось выбрать явно. В Gradio 6+ (текущая версия
> при установке `uv pip install gradio`) формат messages — единственный и
> используется по умолчанию, писать `type=...` не нужно и даже вызовет ошибку
> `TypeError: unexpected keyword argument 'type'`.

Три вещи, которые делает Gradio:

1. рисует страницу чата;
2. при каждом твоём сообщении вызывает функцию `chat(...)`;
3. показывает то, что она вернула.

## Как запустить и что произойдёт

```bash
uv run chat_web.py
```

В терминале появится строка вроде:

```
Running on local URL:  http://127.0.0.1:7860
```

Открой этот адрес в браузере (часто Gradio открывает его сам) — там окно чата.
Печатаешь сообщение → бот отвечает вживую. Чтобы остановить — `Ctrl+C` в терминале.

## Готовый пример в проекте

Файл **`chat_web.py`** — рабочий чат, подключённый к ИИ (по умолчанию бесплатный
локальный Ollama). Запусти и поговори:

```bash
uv run chat_web.py
```

## Поделиться ссылкой (временно)

Добавь `share=True` — Gradio выдаст **публичную ссылку** на ~72 часа, её можно
кинуть другу (работает, пока твой скрипт запущен):

```python
gr.ChatInterface(chat).launch(share=True)
```

## Где разместить навсегда

Локальный Gradio живёт, пока включён твой компьютер. Чтобы 24/7 — заливаешь на
сервер (см. `HOSTING.md`). Для Gradio самый простой бесплатный хостинг —
**Hugging Face Spaces** (создаёшь Space, загружаешь файлы, он сам поднимает чат
по публичной ссылке).

## Шпаргалка

| Хочу                          | Что сделать                                                     |
| ----------------------------- | --------------------------------------------------------------- |
| Чат в браузере локально       | `gr.ChatInterface(chat).launch()` → открыть localhost:7860      |
| Временную ссылку другу        | `.launch(share=True)`                                           |
| Постоянный публичный бот      | выложить на Hugging Face Spaces (или VPS, см. HOSTING.md)       |
| Не только чат, а форму/кнопки | `gr.Interface(...)` / `gr.Blocks(...)` (другие виды интерфейса) |
