# FAQ — что делать, если не работает

> 📖 Красиво смотреть: `Cmd+Shift+V` (Windows: `Ctrl+Shift+V`).

Частые ошибки новичка и быстрые решения. Сначала **прочитай последнюю строку
ошибки** в терминале — обычно там и есть причина.

---

### `zsh: command not found: ollama` (или `uv`, `git`)
Программа не установлена **или** терминал её ещё «не видит».
- Установи её (см. `RESOURCES.md`).
- Потом **закрой и открой терминал заново** — команды подхватываются в новом окне.

---

### `Ollama не отвечает` / `connection refused` / `Could not connect to ollama`
Не запущен движок Ollama или нет модели.
- Убедись, что **приложение Ollama запущено** (на Mac — значок ламы в строке меню).
- Скачай модель: `ollama pull llama3.2` (или `qwen2.5`).
- Проверь: `ollama list` — модель должна быть в списке.

---

### `ModuleNotFoundError: No module named 'X'`
Не установлена библиотека `X`.
- Установи: `uv pip install X`
- Или поставь всё разом: `uv pip install -r requirements.txt`
- Фреймворки ставятся отдельно: `uv pip install openai-agents` / `crewai` / `langgraph`.

---

### `Could not resolve authentication` / «Нет ключа»
Нет ключа выбранного провайдера (Claude / OpenAI / Gemini / DeepSeek / Mistral / YandexGPT).
- Впиши ключ в файл **`.env`** (образец — `.env.example`).
- Для YandexGPT нужен ещё `YANDEX_FOLDER_ID` (ID каталога Yandex Cloud).
- Или переключись на бесплатный путь: в коде `PROVIDER = "ollama"`.
- Какие вообще есть модели (вкл. 🇷🇺 русские) — см. `LANDSCAPE.md`.

---

### `RateLimitError: 429` / «Quota exceeded» / `RESOURCE_EXHAUSTED` (Gemini)
У **бесплатного** тарифа Google Gemini (`gemini-2.5-flash`) очень маленький
лимит — всего **20 запросов В СУТКИ** на модель. Он общий на весь день, а не
на один запуск файла: если ты уже потестировал несколько примеров подряд —
лимит может кончиться уже на 2–3-м вопросе.
- Это не баг кода — это ограничение бесплатного тарифа Google.
- **Для активной разработки и тестов** переключись на бесплатную локальную
  модель: `PROVIDER = "ollama"` (лимитов нет, работает офлайн).
- **Лимит суточный** — на следующий день он обнулится сам.
- Gemini оставляй для финальной демонстрации/показа, а не для перебора
  экспериментов — так 20 запросов растянутся надолго.

---

### `.env` не подхватывается (ключ «не видит»)
- Файл должен называться ровно **`.env`** (не `.env.txt`).
- Он должен лежать в **корне проекта** (рядом с `requirements.txt`).
- После правки `.env` запусти заново.

---

### `address already in use` / порт `7860` занят (Gradio)
Уже запущен прошлый чат.
- Закрой прошлый терминал (`Ctrl+C`) и запусти снова.
- Или укажи другой порт: `.launch(server_port=7861)`.

---

### Бот мешает русский с английским / плохо отвечает
Это **маленькая бесплатная модель** (llama3.2) — она слабовата.
- Возьми модель получше для русского: `ollama pull qwen2.5`, в коде `MODEL = "qwen2.5"`.
- Или используй облачную модель (Claude / GPT / бесплатный Gemini) — заметно умнее.

---

### Работает медленно
Локальная модель считается на твоём компьютере — это нормально, особенно на слабом.
- Возьми модель полегче или облачную (она быстрее).

---

### Файл `.pyc` или папка `__pycache__` — что это?
Это служебный кэш Python. **Не трогай и не читай** его. Открывай только файлы `.py`.

---

> Если ничего не помогло — скопируй **последнюю строку ошибки** и спроси Claude:
> «у меня такая ошибка при запуске — что делать?». Он подскажет.
