# Глоссарий — термины простыми словами

> 📖 Красиво смотреть: `Cmd+Shift+V` (Windows: `Ctrl+Shift+V`).

Короткая шпаргалка по словам, которые встречаются в проекте.

| Термин | Простыми словами |
|---|---|
| **LLM** | большая языковая модель — «мозг» ИИ, который понимает и пишет текст (ChatGPT, Claude, Gemini, llama). |
| **Модель** | конкретный «мозг» (например `llama3.2`, `gpt-4o-mini`). Бывает локальная (на твоём компе) и облачная (на серверах провайдера). |
| **Токен** | кусочек слова (~3–4 буквы). Модели «думают» токенами; по ним же считают длину и стоимость. |
| **Контекст (контекстное окно)** | сколько текста модель помнит за один раз (у современных — до ~1 млн токенов, ~700 страниц). Когда разговор перерастает окно, старое сжимают в резюме или отбрасывают. |
| **Промпт** | то, что ты пишешь модели (запрос/вопрос). |
| **Системный промпт** | тайная инструкция «кем быть» модели (роль, правила). Пользователь её не видит. |
| **Провайдер** | компания, которая даёт модель: Anthropic (Claude), OpenAI (GPT), Google (Gemini), или локальный Ollama. |
| **API** | «правила связи» с моделью по интернету (адрес + формат запроса). |
| **API call** | один запрос к модели по этим правилам (одно обращение). |
| **SDK** | удобная библиотека, которая делает API call за тебя из кода (`anthropic`, `openai`, `ollama`). |
| **Ключ (API key)** | твой «пароль» к платному провайдеру. Хранится в файле `.env`, в код не вписывается. |
| **Агент** | программа, которая не просто отвечает, а действует: думает, вызывает инструменты, повторяет — в цикле, пока не решит задачу. |
| **Инструмент (Tool Calling)** | функция, которую модель может вызвать, чтобы СДЕЛАТЬ что-то реальное (посчитать, записать, отправить). |
| **Паттерн** | типовая «схема сборки» агента (Chain, Router, Judge, Memory и т.д.). Кирпич, из которого собирают ботов. |
| **Фреймворк** | готовая «обвязка» для агентов (CrewAI, LangGraph, OpenAI Agents SDK) — пишешь меньше кода, но больше «магии». |
| **RAG** | «генерация с подглядыванием в свои данные»: даёшь модели свои факты (базу знаний), чтобы она отвечала по ним, а не выдумывала. |
| **Структурированный вывод** | когда модель возвращает строгий формат (JSON с полями), а не свободный текст — удобно передавать дальше. |
| **Память (Memory)** | хранение контекста, чтобы бот не забывал разговор (или помнил между запусками — в файле/базе). |
| **Gradio** | библиотека, которая превращает твою функцию в чат/интерфейс в браузере. |
| **Хостинг / деплой** | размещение бота на сервере, чтобы он работал 24/7, а не только пока включён твой компьютер. |
| **Эмбеддинги** | способ превратить текст в числа, чтобы искать «по смыслу» (используется в настоящем RAG для больших баз). |

> Не понял слово, которого тут нет? Спроси Claude: «объясни простыми словами, что такое …».
