# Карта рынка: фреймворки, модели и no-code

> 📖 Красиво смотреть: `Cmd+Shift+V` (Windows: `Ctrl+Shift+V`).

Этот файл — обзорная «карта местности». Не нужно учить всё подряд: гораздо
важнее **знать, что существует** и для чего, чтобы выбрать инструмент под задачу.
Главная мысль всего проекта: под капотом все делают одно и то же (зовут модель,
дают ей инструменты, гоняют по кругу) — **меняется только синтаксис**.

---

## 1. Фреймворки для агентов

Фреймворк — это «готовая кухня»: за тебя уже написаны цикл агента, вызов
инструментов, память, передача задач между агентами. Ты пишешь меньше, но
играешь по правилам фреймворка.

### Уже разобраны в этом проекте

| Фреймворк | Идея в одном предложении | Папка |
|---|---|---|
| **OpenAI Agents SDK** | минималистичный агент: `Agent` + `Runner` + инструменты | `02-openai_sdk/` |
| **CrewAI** | «команда ролей»: агенты с профессиями делят задачи | `03-crewai/` |
| **LangGraph** | агент как **граф**: узлы и рёбра, силён в памяти и сложной логике | `04-langgraph/` |

### Что ещё есть на рынке (знать, что существует)

| Фреймворк | Для чего | Стоит ли копать |
|---|---|---|
| **LangChain** | «дедушка» всех, огромная экосистема; LangGraph — его часть | если нужна готовая интеграция почти с чем угодно |
| **LlamaIndex** | заточен под **данные и RAG** (поиск по своим документам) | когда главное — отвечать по большой базе знаний |
| **Pydantic AI** | новый, **типобезопасный**, строгие структуры данных | если любишь строгий, предсказуемый код |
| **Microsoft AutoGen** | мульти-агентные «диалоги»: агенты переговариваются между собой | сложные сценарии с несколькими ИИ |
| **Semantic Kernel** | фреймворк от Microsoft, дружит с .NET/корпоративным миром | корпоративная разработка |
| **Google ADK** (Agent Development Kit) | агенты в экосистеме Google / Vertex AI | если ты в Google Cloud |
| **Smolagents** (Hugging Face) | минимализм: агент в несколько строк | быстрый прототип |
| **DSPy** | не про агентов, а про **автоподбор промптов** | когда хочется «обучать» промпты, а не писать руками |

> 🧭 **Вывод:** фреймворков десятки, но принцип у всех один. Освоив 2–3 (как в
> этом проекте), новый осваиваешь за вечер — меняется обёртка, не суть.

## 2. Модели (нейросети — «мозг» агента)

Модель — это и есть ИИ, который думает. Код агента один, а «мозг» можно подменять.
В голом коде это делается одной строкой `PROVIDER = ...` прямо вверху каждого
файла (быстрый выбор: `ollama` / `gemini`); полный список из 7 провайдеров —
в `01-pure_python/llm.py`.

### Локальные (бесплатно, на твоём компьютере, через Ollama)

| Модель | Заметка |
|---|---|
| **llama3.2** (Meta) | лёгкая и быстрая, но слабовата, может мешать языки |
| **qwen2.5** (Alibaba) | **заметно лучше понимает русский** — бери её для РФ-задач |

Плюс: бесплатно и приватно (ничего не уходит в облако). Минус: слабее облачных,
грузит твой компьютер.

### Облачные зарубежные (по API, обычно платно)

| Модель | Кто | Заметка |
|---|---|---|
| **Claude** | Anthropic | сильная в рассуждениях и работе с инструментами |
| **GPT** | OpenAI | самая известная, большая экосистема |
| **Gemini** | Google | 🆓 на момент записи курса есть **бесплатный** доступ по API, но лимит маленький — всего ~20 запросов в сутки на модель, см. `FAQ.md` |
| **DeepSeek** | DeepSeek | очень **дёшево** при хорошем качестве, OpenAI-совместима |
| **Mistral** | Mistral (Европа) | есть бесплатный лимит, открытые модели |
| **Grok** | xAI | для общего кругозора |
| **Perplexity** | Perplexity | ответы **с поиском в интернете** |

### 🇷🇺 Русские (оплата в рублях, без зарубежной карты)

| Модель | Кто | Как подключить |
|---|---|---|
| **YandexGPT** | Яндекс | **уже работает** в `llm.py`: `PROVIDER = "yandex"` + ключ и `YANDEX_FOLDER_ID` в `.env` |
| **GigaChat** | Сбер | подключается по своей схеме — см. ниже |

**Почему это важно:** не нужна иностранная карта и зарубежный счёт — частая боль.

#### Как подключить GigaChat (Сбер)

GigaChat не «OpenAI-совместим» напрямую: вход через **OAuth-токен**, есть свой
пакет. Кратко:

1. Получи доступ и `Authorization key` в личном кабинете GigaChat (Сбер).
2. Поставь пакет: `uv pip install gigachat`
3. Минимальный вызов:

```python
from gigachat import GigaChat

# verify_ssl_certs=False — частый момент: у Сбера свои сертификаты.
with GigaChat(credentials="ТВОЙ_AUTHORIZATION_KEY", verify_ssl_certs=False) as giga:
    response = giga.chat("Привет! Скажи одно дружелюбное предложение.")
    print(response.choices[0].message.content)
```

> Это отдельный путь от `llm.py` (там — только OpenAI-совместимые провайдеры).
> Если GigaChat станет основным — можно завести по аналогии свою функцию `ask()`.

## 3. No-code / low-code (собрать агента мышкой, без кода)

Иногда код вообще не нужен — логика собирается из блоков в визуальном редакторе.

| Инструмент | Чем известен |
|---|---|
| **n8n** | мощная автоматизация, тысячи интеграций, можно self-host |
| **Make** (бывш. Integromat) | визуальные сценарии «если это → то то» |
| **Flowise** | визуальный конструктор LLM-приложений (на базе LangChain) |
| **Langflow** | похоже на Flowise, drag-and-drop графы |
| **Dify** | платформа для ИИ-приложений и чат-ботов с UI |

**Аналогия трёх уровней (как в README):**

```
голый код (01-pure_python)  ↔  чистый CSS   — всё руками, максимум контроля
фреймворк (02/03/04)         ↔  Tailwind     — тоже код, но короче
no-code (n8n / Flowise)      ↔  Tilda/Webflow — мышкой, без кода
```

## Как выбирать (короткая шпаргалка)

- **Учусь / нужен максимум контроля** → голый код + локальная модель (бесплатно).
- **Нужна модель поумнее даром** → Gemini (бесплатный лимит) или локальная qwen2.5.
- **Важна цена за объём** → DeepSeek.
- **Нельзя зарубежную карту** → YandexGPT / GigaChat (рубли).
- **Сложная логика / память / много агентов** → фреймворк (LangGraph, CrewAI).
- **Хочу без кода** → n8n / Flowise.

> Не гонись за «самым модным». Бери под задачу самое простое, что её решает.
