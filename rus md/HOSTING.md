# Где в итоге «живут» эти боты? (хостинг)

Ты запускаешь файлы командой `uv run ...` — и бот работает, пока включён твой
компьютер и открыт терминал. Этот файл объясняет, как сделать, чтобы бот
работал сам, 24/7, в интернете.

## Главное: хостятся ДВЕ разные вещи

Любой бот в этом проекте (хоть голый код, хоть на фреймворке) — это обычная
Python-программа. У неё два «жителя», и они могут находиться в разных местах:

```
1) ТВОЙ КОД агента  → крутится где-то на сервере (комп / VPS / облако)
2) МОДЕЛЬ (мозг ИИ)  → либо локально (Ollama), либо на серверах
                       провайдера по API (OpenAI / Claude / Google)
```

Например: код живёт на дешёвом сервере, а «думает» через облачный Claude.
Или и код, и модель (Ollama) — на одном своём сервере. Комбинации любые.

## Лесенка хостинга твоего КОДА

| Где                                      | Что это                                        | Когда подходит                                    |
| ---------------------------------------- | ---------------------------------------------- | ------------------------------------------------- |
| 🖥️ **Локально**                          | твой компьютер (`uv run`)                      | разработка и тесты; работает, пока комп включён   |
| ☁️ **Свой сервер / VPS**                 | Railway, Render, Fly.io, Hetzner, DigitalOcean | продакшн 24/7: заливаешь код — он крутится всегда |
| ⚡ **Serverless**                        | Vercel, AWS Lambda, Google Cloud Run, Modal    | запуск «по запросу»; платишь за использование     |
| 🤖 **Управляемые платформы под агентов** | хостинг от создателей фреймворка (см. ниже)    | деплой + память + мониторинг «из коробки»         |

Чем ниже по таблице — тем меньше думаешь про сервер, но больше платишь/зависишь
от платформы.

## Бесплатно или платно? (важно — проверь актуальные цены)

Цены у хостингов меняются, но на момент написания картина такая:

| Где | Бесплатно? |
|---|---|
| 🖥️ **Локально** (`uv run`) | ✅ полностью бесплатно (пока комп включён) |
| 🤗 **Hugging Face Spaces** | ✅ **есть бесплатный тариф — лучший вариант для Gradio-бота** |
| ☁️ **Railway** | ⚠️ пробный кредит **$5** (сгорает за 30 дней), дальше **$5/мес** (Hobby) |
| ☁️ **Render** | ⚠️ есть бесплатный тариф, но сервис **«засыпает»** при простое |
| ⚡ **Vercel** | ✅ бесплатный тариф есть, но это serverless (для сайтов, не для ботов с памятью) |

**Хочешь выложить Gradio-бота бесплатно и навсегда → Hugging Face Spaces.**
Railway хорош, когда нужно «дёшево и по-взрослому» (с базой данных в пару кликов),
но это уже **не бесплатно** для постоянной работы.

## У каждого фреймворка есть «родная» платформа хостинга

| Фреймворк              | Своя платформа                                                                                     |
| ---------------------- | -------------------------------------------------------------------------------------------------- |
| **LangGraph**          | LangGraph Platform (LangChain) — деплой графов + память + мониторинг (LangSmith)                   |
| **CrewAI**             | CrewAI AMP / Enterprise — деплой «команд»                                                          |
| **Google ADK**         | Vertex AI Agent Engine — управляемый хостинг в Google Cloud                                        |
| **OpenAI Agents SDK**  | своей хостинг-платформы для кода нет — крутишь сам (VPS / serverless). OpenAI хостит только модели |
| **Claude (Anthropic)** | Claude on the web / Managed Agents — облачные сессии агентов                                       |

Использовать «родную» платформу не обязательно — код любого фреймворка можно
залить на обычный VPS.

---

## А если без кода (no-code)?

Инструменты **n8n / Flowise / Make** — там бот собирается мышкой, кода нет, и
хостинг встроенный: либо облако самого сервиса, либо self-host на своём сервере.

---

## Простыми словами

> Бот — это программа. Чтобы она работала круглосуточно (а не пока включён твой
> компьютер), её **заливают на сервер**: свой (VPS вроде Railway) или управляемый
> (LangGraph Platform, Vertex Agent Engine и т.п.). Модель при этом либо
> локальная (Ollama на том же сервере), либо облачная (по API провайдера).

---

## Как выбрать (короткая шпаргалка)

- **Просто попробовать / учиться** → локально (`uv run`).
- **🆓 Бесплатно выложить Gradio-бота** → Hugging Face Spaces.
- **Маленький бот 24/7, дёшево (но платно)** → Railway ($5/мес после пробного кредита) или Render.
- **Запуск редкий / по событию** → serverless (Vercel, Cloud Run).
- **Сложный агент + нужна память и мониторинг** → управляемая платформа фреймворка.
- **Без кода вообще** → n8n / Flowise (их же облако).
