# Ресурсы и установка (что поставить, чтобы всё работало)

Здесь собрано всё, что нужно установить **один раз**, чтобы проект заработал.
Фреймворки (openai-agents, crewai, langgraph) ставить пока **не нужно** — их
поставим позже, отдельно.

> таблицами, а не сырым текстом), нажми в редакторе:
> **macOS:** `Cmd + Shift + V`  ·  **Windows:** `Ctrl + Shift + V`

## 1. VS Code — редактор кода

Программа, в которой ты открываешь и читаешь файлы проекта. Бесплатная.

🔗 Скачать: **https://code.visualstudio.com/download**
(на странице выбери свою систему — macOS или Windows — и установи как обычное приложение).

**Что это даёт:** удобно смотреть код, открывать `.md` в превью (`Cmd+Shift+V`),
запускать встроенный терминал (меню *Terminal → New Terminal*).

## 2. uv — менеджер пакетов и Python

`uv` — современный инструмент, который ставит библиотеки и сам управляет Python.
Заменяет старый `pip`. Через него ты запускаешь файлы (`uv run ...`).

🔗 О нём: **https://github.com/astral-sh/uv**

**macOS / Linux** (вставь в терминал и нажми Enter):
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**Windows** (открой PowerShell и вставь):
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**Что делает команда:** скачивает и устанавливает `uv`. После установки **закрой
и открой терминал заново**, затем проверь: `uv --version` — должна показаться версия.

## 3. Ollama — бесплатный локальный ИИ (без ключей и оплаты)

Приложение, которое запускает нейросети **прямо на твоём компьютере**. Нужно,
чтобы бесплатные примеры работали без всяких ключей.

🔗 Скачать: **https://ollama.com/download**

**macOS:** скачай приложение по ссылке и перетащи в «Программы», затем запусти
его один раз (появится значок ламы в строке меню).
Альтернатива через терминал:
```bash
brew install ollama
```

**Windows:** скачай установщик по ссылке и установи (Ollama запустится сама в фоне).
Альтернатива через терминал:
```powershell
winget install Ollama.Ollama
```

**Что делает:** ставит «движок». Сам по себе он пустой — дальше надо скачать
«мозг» (модель).

### Скачать модели (команды одинаковые на macOS и Windows)

```bash
ollama pull llama3.2
```
**Что делает:** качает модель **llama3.2** (~2 ГБ) — лёгкая, быстрая, для общих
задач. Качается один раз, дальше работает офлайн.

```bash
ollama pull qwen2.5
```
**Что делает:** качает модель **qwen2.5** — она **заметно лучше понимает русский**,
чем llama3.2. Если ответы на русском важны — используй её.

> Какую модель использовать, задаётся в коде строкой `MODEL = "..."`
> (например `"llama3.2"` или `"qwen2.5"`).

### 🆓 Бесплатно, но облачно: Google Gemini

Не хочешь ставить Ollama (или нужна модель поумнее)? **На момент записи курса
Google даёт БЕСПЛАТНЫЙ доступ к Gemini по API.** Это облачная модель — умнее
локальной, и при этом даром (бесплатный лимит; условия со временем могут меняться).

1. Получи бесплатный ключ: **https://aistudio.google.com/apikey**
2. Впиши его в файл `.env` (строка `GOOGLE_API_KEY=...`).
3. В коде поставь провайдер Gemini: строку `PROVIDER = "gemini"` вверху
   любого файла из `01-pure_python/` — она уже стоит там по умолчанию.

Так можно учиться на хорошей облачной модели **без оплаты**.

> 🗺️ Какие вообще бывают модели и фреймворки (включая дешёвый DeepSeek и
> 🇷🇺 русские YandexGPT / GigaChat — оплата в рублях, без зарубежной карты) —
> смотри обзорный файл `LANDSCAPE.md`.

## 4. Библиотеки проекта (без фреймворков)

Базовые библиотеки, нужные голому коду и чату. **Фреймворки сюда НЕ входят.**
Выполняй из папки проекта (там, где лежит `requirements.txt`).

**macOS и Windows** (одинаково):
```bash
uv venv
uv pip install -r requirements.txt
uv pip install gradio
```

**Что делают команды:**
- `uv venv` — создаёт «ящик» для библиотек проекта (папка `.venv`).
- `uv pip install -r requirements.txt` — ставит базовые библиотеки
  (ollama, anthropic, openai, python-dotenv).
- `uv pip install gradio` — ставит Gradio (для чата в браузере, `chat_web.py`).

## 5. Git — чтобы скачать (склонировать) проект

Git нужен, чтобы скачать проект с репозитория одной командой.

🔗 Windows-установщик: **https://git-scm.com/download/win**

**macOS:** обычно уже стоит. Если нет — поставится так:
```bash
xcode-select --install
```
или через `brew install git`.

**Windows:** установи по ссылке выше (обычная установка «Далее → Далее»).

**Проверка:** `git --version` — должна показаться версия.

Скачать проект (когда будет ссылка на репозиторий):
```bash
git clone ССЫЛКА_НА_РЕПОЗИТОРИЙ
```
