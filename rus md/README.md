# Foundations — паттерны AI-агентов

Учебный проект: основные паттерны построения AI-агентов, показанные на **трёх
уровнях** — от голого кода до фреймворка. Каждый файл густо закомментирован
«для тупых» и снабжён предохранителями от ошибок.

## Структура проекта

```
foundations-practice/
├── 01-pure_python/     ← УРОВЕНЬ 1: голый код (всё руками, максимум контроля)
│   ├── llm.py       ← движок: любой провайдер (Ollama/Claude/GPT/Gemini)
│   └── 00..13.py    ← паттерны (basic, chain, judge, router, tools, ...)
│
├── 02-openai_sdk/      ← УРОВЕНЬ 2: те же паттерны на ФРЕЙМВОРКЕ (OpenAI Agents SDK)
│   └── 01,04,06,09  ← короче, готовые блоки
│
├── 03-crewai/          ← УРОВЕНЬ 2 (другой фреймворк): «команда ролей» (CrewAI)
│   └── 01,09        ← Agent + Task + Crew
│
├── 04-langgraph/       ← УРОВЕНЬ 2 (другой фреймворк): «агент как граф» (LangGraph)
│   └── 01,03        ← узлы + рёбра + состояние, цикл «судьи»
│
├── 05-example_bot/     ← 🎯 ЭТАЛОННЫЙ бот-консультант (все паттерны вместе)
```

## Установка (один раз)

> 📁 `~/Downloads/foundations-practice` ниже — это ПРИМЕР пути. У тебя папка
> проекта может лежать в другом месте (Desktop, Downloads, куда угодно) и
> называться иначе. Замени путь на свой: проще всего написать в терминале
> `cd ` (с пробелом) и перетащить туда папку проекта мышкой из Finder — путь
> подставится сам.

```bash
cd ~/Downloads/foundations-practice   # ← впиши СВОЙ путь к папке проекта
uv venv
uv pip install -r requirements.txt        # библиотеки голого кода
uv pip install openai-agents              # фреймворк (для папки 02-openai_sdk)
```

## Как запускать

**Голый код** (бесплатно на Ollama — по умолчанию):
```bash
cd ~/Downloads/foundations-practice   # ← тот же путь, что и выше — свой, не этот пример
uv run 01-pure_python/00_chain.py
uv run 01-pure_python/06_router.py
# ...и т.д.
```

**Фреймворк** (нужен ключ OpenAI в .env):
```bash
uv run 02-openai_sdk/01_basic.py
```

## Провайдеры (голый код)

В **каждом** файле папки `01-pure_python/` в самом верху есть свой переключатель:
```python
PROVIDER = "gemini"   # "ollama" (🆓 локально, бесплатно) | "gemini" (облако Google)
```
Специально сделано так, а не в одном общем файле — открыл конкретный файл,
сразу видишь и меняешь модель именно в нём, ничего искать не нужно.

Ключ для Gemini — в `.env` (образец в `.env.example`, переменная `GOOGLE_API_KEY`,
бесплатный лимит: https://aistudio.google.com/apikey). Поставишь `PROVIDER = "ollama"` —
всё работает **бесплатно и локально**, ключ вообще не нужен.

> 🗺️ Есть и отдельный файл `01-pure_python/llm.py` — универсальный движок сразу
> под 7 провайдеров (Claude, OpenAI, DeepSeek, Mistral, YandexGPT и другие). Он
> не используется файлами-паттернами напрямую (у них свой простой переключатель),
> но полезен как справка и как готовый «одна точка входа» приём, если решишь
> собирать свой большой проект. Полный обзор моделей и фреймворков — в [`LANDSCAPE.md`](LANDSCAPE.md).

> 🆓 На момент записи курса у Google есть **бесплатный доступ к Gemini по API**
> (бесплатный лимит; условия со временем могут меняться) — поэтому во всех
> файлах по умолчанию стоит `PROVIDER = "gemini"`.

## Предохранители

Если запустить без нужного ключа/библиотеки — вместо страшной ошибки выпадет
понятное сообщение, что делать. Бесплатные файлы (Ollama) работают сразу.
